# Feature list

Status: **Seeded**. Last updated: 2026-11-04. The full list of ideas lives in
the [idea bank](../idea/05-idea-bank.md). This section turns them into a
prioritised feature list with acceptance criteria.

## First draft of the MVP

Taken from the idea bank items tagged `MVP`. Not frozen.

| Area | Features | Idea IDs |
|---|---|---|
| Circles | Create a circle, invite by link or QR, join, leave | P-35 |
| Daily drop | One drop per circle, 24-hour window, rotating Speaker | P-02 |
| Round | Seal → claim → True/Bluff vote → number guess → reveal → points | P-01, P-05, P-14 |
| Data | Manual entry with optional screenshot badge | P-45, P-16 |
| League | Monthly season, skill-only points, fresh start | P-03 |
| Finale | Every member gets a play-style title; share card with no raw stats | P-04, P-30 |
| Comfort | Per-stat opt-in, invisible pass, away status, catch-up card, rest day, emoji-only reactions | P-18 to P-20, P-22, P-23, P-25 |
| Personal | Focus lanes; private "my month" | P-27, P-28 |
| Fairness | Server-side scoring | P-17 |
| Privacy | Delete my data, leave circle | P-26 |

## Explicitly not in the MVP

Auto-reading stats (P-46 to P-48), contact sync (P-36), other card types
(P-38 to P-41), circle vs circle (P-37), voice claims (P-42).
