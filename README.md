# BLAG: Are You Bluffing?

> Your people. Their stats. Your call.

BLAG is a privacy-first social game for close friend groups. It turns
digital wellbeing into ten minutes of daily fun. Each day a friend makes a
claim about their own habits (screen time, steps, late-night use), the circle
votes **True** or **Bluff**, and the real number is revealed. Daily points
build into a monthly league that ends in a finale where every member is
recognised.

**Status:** pre-development. There is no app code yet. This repository
currently holds the knowledge base that has to be researched and agreed
before development starts.
